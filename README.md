                                Calculator
A Python 3 calculator used from the Terminal, built step by step in SCCM4910.

## How to test
1. use the SCCM4910 environment 
	source /opt/python-venv/sccm-4910/bin/activate

2. run ./check.sh all confirm all 5 test cases are passed

3. run echo $? to check exit code is 0

Add, subtract, multiply and divide two numbers; display the result.
## How to run it

1. run: ./run.sh

2. Enter the first number, operator (+ - * /), then second number.

3. The program prints Result: followed by the answer.
